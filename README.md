## Topics Covered

### 1. Dictionaries (`dict/`)
Collection of programs demonstrating dictionary methods and operations:
- `dict-01.py` to `dict-10.py`: Key-value pairs, nested dictionaries, iterations, and dictionary comprehension.

### 2. Functions (`functions/`)
Programs demonstrating user-defined functions:
- `py-fn01.py`: Basic function definition and return types.
- `fn02.py`: Function parameters, arguments, and scope.
- `fn03.py`: Advanced function implementations and practice.

### 3. Basic Scripts
Introductory Python practice programs:
- `python-01.py`: Syntax and variable fundamentals.
- `python-02.py`: Basic arithmetic and operators.
- `python-03.py`: Control flow and branching.

## Assignments

### Assignment 2 (`assignment-2/`)
- `task1.py`: Check whether a given integer is even or odd.
- `task2.py`: Calculate the sum of numbers from 1 to 50 using a loop.

### Assignment 3 (`om-assignment-3/`)

### Assignment 4 (`om-assignment-4/`)
- `task1.py`: Safe file reading with try-except error handling for `FileNotFoundError`.

## How to Run

Clone the repository and run any program using the Python interpreter:

```bash

git clone https://github.com/ommd3076/python-programs-L-.git

# Navigate into the project directory
cd python-programs-L-

# Run a specific script
python assignment-2/task1.py
```
